# 🎵 YouTube Music Downloader & Auto-Sync to Flash Drive

สคริปต์ Batch และ PowerShell สำหรับดาวน์โหลดเพลงจาก YouTube Playlist แปลงเป็นไฟล์ MP3 คุณภาพสูง และซิงค์ลง Flash Drive แบบอัตโนมัติ (True Sync) รองรับการจัดเรียงหมายเลขแทร็ก (Track Number) และฝังภาพปกลงในไฟล์เพื่อใช้เปิดฟังบนเครื่องเสียงรถยนต์หรือเครื่องเล่นเพลงทั่วไปได้อย่างสมบูรณ์แบบ

---

## Features

- ⚡ **รันได้ทันที**: ไม่ต้องติดตั้งโปรแกรมอะไรล่วงหน้า สคริปต์จะดาวน์โหลดเครื่องมือที่จำเป็น (`yt-dlp`, `ffmpeg`, `deno`) ให้แบบอัตโนมัติในการรันครั้งแรก
- 🎧 **คุณภาพเสียงสูงสุด**: บันทึกเป็นไฟล์ MP3 คุณภาพดีที่สุด (`--audio-quality 0` / 320 kbps)
- 🖼️ **ฝังภาพปก & ข้อมูลเพลงครบถ้วน**: แปลงภาพปกเป็น JPG ฝังเข้า Tag ID3v2.3 พร้อม Artist และ Title อย่างถูกต้อง
- 🔄 **Sync เพลงให้ตรงกับ Playlist เสมอ**:
  - เพลงที่เคยโหลดไว้แล้วจะถูกข้าม ไม่โหลดซ้ำ
  - หากมีเพลงที่ถูกลบออกจาก YouTube Playlist สคริปต์จะค้นหาและลบเพลงนั้นออกจาก Flash Drive ให้อัตโนมัติ
- 🔢 **เรียงลำดับ Track Number อัตโนมัติ**: จัดเรียง Tag Track Number (`1/N` ถึง `N/N`) ตามลำดับเพลงใน YouTube Playlist ทำให้เครื่องเสียงรถยนต์เล่นเพลงตามลำดับที่คุณจัดไว้ใน Playlist เสมอ

---

## 📋 Requirements

- **ระบบปฏิบัติการ**: Windows 10 หรือ Windows 11 (มีคำสั่ง `curl.exe`, `tar.exe` และ `powershell.exe` ติดตั้งมาพร้อมกับ Windows อยู่แล้ว)
- **การเชื่อมต่อ**: อินเทอร์เน็ตสำหรับดาวน์โหลดเครื่องมือและเพลง
- **Flash Drive**: เสียบเข้ากับคอมพิวเตอร์ (ค่าเริ่มต้นคือ Drive `E:`)

## 🚀 วิธีตั้งค่าและใช้งาน

### 1. ดาวน์โหลดโค้ด
Clone ดาวน์โหลดโปรเจกต์นี้มาไว้ในเครื่องของคุณ:
```bash
git clone https://github.com/WoodMMK/youtube-music-downloader.git
```

### 2. กำหนดลิงก์ YouTube Playlist
ทำได้ 2 วิธี (เลือกวิธีใดวิธีหนึ่ง):

- **วิธีที่ 1 (แนะนำและปลอดภัยที่สุด)**:  
  สร้างไฟล์ชื่อ `playlist.txt` ไว้ที่โฟลเดอร์เดียวกันกับ `script.bat` แล้ววางลิงก์ Playlist ของคุณลงไป เช่น:
  ```text
  https://www.youtube.com/playlist?list=PLxxxxxxxxxxxxxxxx
  ```
  *(ไฟล์ `playlist.txt` ถูกตั้งค่าใน `.gitignore` ไว้แล้ว ลิงก์ส่วนตัวจะไม่ถูก push ขึ้น Git)*

- **วิธีที่ 2**:  
  เปิดไฟล์ `script.bat` ด้วย Text Editor (Notepad / VS Code) แล้วแก้ไขบรรทัด:
  ```bat
  set "PLAYLIST_URL=https://www.youtube.com/playlist?list=YOUR_PLAYLIST_ID"
  ```

### 3. ตั้งค่า Drive Letter ของ Flash Drive (ถ้าจำเป็น)
เปิดไฟล์ `script.bat` และตรวจสอบบรรทัด:
```bat
set "DRIVE=E"
```
- หาก Flash Drive ของคุณไม่ใช่ Drive `E:` ให้เปลี่ยนเป็นตัวอักษร Drive ของคุณ เช่น `D`, `F`, `G`
- เพลงจะถูกบันทึกไปที่ `<DRIVE>:\Music\`
- บันทึกประวัติการดาวน์โหลดไว้ที่ `<DRIVE>:\downloaded.txt`

### 4. เริ่มใช้งาน
- **ดับเบิลคลิกไฟล์ `script.bat`** เพื่อเริ่มทำงาน
- ในการรันครั้งแรก สคริปต์จะดาวน์โหลด `yt-dlp.exe`, `ffmpeg.exe`, `ffprobe.exe`, `deno.exe` มาเก็บไว้ในโฟลเดอร์นี้ให้อัตโนมัติ
- สคริปต์จะเริ่มดาวน์โหลดเพลง แปลงเป็น MP3 ฝังภาพปก และซิงค์ลำดับเพลงจนเสร็จสมบูรณ์

## 📁 โครงสร้างโปรเจกต์ (Project Structure)

```text
youtube-music-downloader/
├── script.bat               # สคริปต์หลักสำหรับรันดาวน์โหลดและซิงค์
├── playlist.txt.example     # ไฟล์ตัวอย่างสำหรับการระบุ Playlist URL
├── .gitignore               # กำหนดไม่ให้เอาไฟล์ binary และข้อมูลส่วนตัวขึ้น Git
└── README.md                # คู่มือการใช้งาน
```

> **หมายเหตุ:** ไฟล์เครื่องมือ (`*.exe`) ที่สคริปต์ดาวน์โหลดมา เช่น `yt-dlp.exe`, `ffmpeg.exe`, `deno.exe` จะถูกยกเว้นใน `.gitignore` ไม่ถูกนำขึ้น GitHub เนื่องจากขนาดไฟล์ใหญ่ และผู้ใช้แต่ละคนสามารถให้สคริปต์โหลดเวอร์ชันล่าสุดได้เอง

## 🛠️ เครื่องมือที่สคริปต์เรียกใช้อัตโนมัติ
- [yt-dlp](https://github.com/yt-dlp/yt-dlp) - ตัวดาวน์โหลดวิดีโอ/เสียงคุณภาพสูง
- [FFmpeg](https://ffmpeg.org/) - ตัวแปลงไฟล์เสียงเป็น MP3 และจัดการ ID3 Tag
- [Deno](https://deno.land/) - ตัวรัน JavaScript Runtime สำหรับซัพพอร์ตการทำงานของ yt-dlp
